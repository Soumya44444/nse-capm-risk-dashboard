\# NSE CAPM Risk Dashboard



Interactive CAPM and Risk Analytics Dashboard for NSE Stocks using Python, Panel, Plotly, and yFinance.



\## Features



\- CAPM-based expected return analysis

\- Beta calculation for NSE stocks

\- Sharpe Ratio analysis

\- Sortino Ratio analysis

\- Calmar Ratio analysis

\- CAGR and Maximum Drawdown calculation

\- Security Market Line (SML) visualization

\- Interactive Plotly dashboard

\- CSV export support

\- Risk-return comparison for NSE stock universe



\## Technologies Used



\- Python

\- Panel

\- Plotly

\- Pandas

\- NumPy

\- yFinance
